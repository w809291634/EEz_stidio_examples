## 页面关系

- `tab_main`（tabview 屏）：tab0=表盘内容、tab1=applist 内容，左右滑切
- `tab_main.tab1` 行点击 → `app_*`（14 页）；`app_*` 返回钮 → `tab_main.tab1`
- `app_alarm`：al_add → `alarm_editor`（返回 → app_alarm）
- `app_settings` 行 → `set_brightness` / `set_sound` / `set_facestyle` / `set_bt` /
  `set_dnd` / `set_about`（返回 → app_settings）
- 无 top bar / bottom bar；除 tab_main 外不平级滑动
