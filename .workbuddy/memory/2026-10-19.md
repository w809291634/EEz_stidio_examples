## 新增 `gesture-page-switch/`（用户点名：页面手势切换，要求不会 checks 空转/不会出错）

- 方案：多个独立 screen + GESTURE 离散切屏（3 页循环 A↔B↔C），**不用 tabview 跟手**——绕开 P-0123 互斥。
- 防「checks 空转」双保险：① Switch 的 `evt` 自定义输入显式 `type:'any'`（§48 实证缺了 EEZ 后台 Checks 检查器持续转圈）；
  ② 导航**完全不依赖 CHECKED 高亮链**（无共享选中态，杜绝状态来回翻）。
- 防「出错」：changeScreen `fadeMode:'NONE'`（绕开 P-0029 动画竞态拉回旧 tab）；GESTURE 双线用裸名
  `GESTURE`（执行线→`@seqin`、数据线→`evt`），避开 §11.41 的 `GESTURE@seqout` 静默丢线陷阱；
  host 容器去掉 `GESTURE_BUBBLE` 收手势（子 label 保留冒泡）。
- 范本来源：`Design Watch/design/make_gesture_repro.py`（repro_ok 形态，含 evt.type 关键差异）。
- 验证：CLI headless 构建 0 错 0 警（EEZ 自带 "No error and no warning detected"）；screens.c 已为 3 个
  host 注册 `LV_EVENT_GESTURE` 回调并移除 GESTURE_BUBBLE；流定义资产（ui.c assets 2764B）含完整组件+连线。
- 限制：手势运行时行为按 P-0141 **只能 PC_SIM/真机验收**，Run 预览不产生 GESTURE 事件（已在 README 明示）。
- 根 README 第 3 节索引表已加一行。
