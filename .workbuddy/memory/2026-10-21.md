## app-wifi-connect2：修复 Wi-Fi 名称横向跑马灯（P-0168 已入库）

- 现象：用户报"Wi-Fi 名称在滚动"——每行 SSID 在行内横向自动滚动，停不下来。
- 根因（三事实叠加）：
  1. `lv_list_add_button` 自带 label 默认 `LV_LABEL_LONG_MODE_SCROLL_CIRCULAR`；
  2. refr_text 用**当前 coords** 与文字宽比较启停动画，而新建对象当拍 coords=0
     （`lv_obj_set_size` 不同步 coords，要等 layout），文字宽 84 > 0 → 无限动画当场启动；
  3. 之后设尺寸/首帧布局刷新都不重跑 refr_text → 动画永不停。
- 修复：`build_row()` 里 `lv_label_set_long_mode(ssid, LV_LABEL_LONG_MODE_CLIP)`
  （set_long_mode 内部先 lv_anim_delete 旧动画；CLIP 是纯绘制期裁剪，永不起动画）。
  不用 DOTS：9.4 的 DOTS 只管垂直溢出，单行超宽不截断也不加"…"。
- 验证法（可复用）：间隔 1s 连拍两张截图 PIL diff——修复前 SSID 带 72 行像素变化，
  修复后 0 变化；截图目视 12 行名称完整静止。无头钩子 WIFI_SHOT2 用完已撤。
- 沉淀：经验库 P-0168（intake/index.md 已加行）。教训：单张截图会漏掉潜伏动画，
  "静止 UI"验收一律用连拍 diff。

## EEZ GUI 字体提取报错修复（用户截图：Font "cn14" extraction failed 0x30fb）
- 根因：托管 Python 没装 fontTools → build_example.py 的 _filter_by_font_cmap 静默跳过 →
  GB2312 符号区的 U+30FB（・）进 lvglRanges，SimHei 无此字形，EEZ GUI 提取失败。
- 修复：pip install fontTools（managed 3.13.12）→ 重新 build_example.py（dropped ・）+
  cli_build + gen_font + run_sim 重编；12 rows from io 正常，截图无回归。
- 教训：过滤逻辑失败必须显式 WARN（已有），但更稳的是 fontTools 缺失时直接 fail 而非降级。

## 字体问题根治（P-0169 沉淀）：防御改硬失败
- 根因确定：build_example.py 的 _filter_by_font_cmap 遇 fontTools 缺失只 WARN 并原样返回，
  脏字符集（U+30FB ・）漏进 lvglRanges → EEZ GUI 提取必报 extraction failed；换环境/缺工具就再犯。
- 双修：① pip install fontTools（已进托管 3.13.12 venv）；② except ImportError 改为
  sys.exit(2) 硬失败（明确提示安装命令），绝不静默降级。已写 P-0169 经验条目。
- 结论性纪律：凡"工具缺失→过滤/校验跳过→脏数据进产物"的防御必须硬失败，不能降级。
