## 2. 密码页（点击带锁行进入 · 独立整页）

- **整页覆盖**：密码页是一整页（独立 screen / 全屏容器），480×320 全部盖住列表，
  **不做半屏抽屉、不做弹层**；
- 返回 ‹（左上）+ SSID 18px + 副标题「WPA3 · 5 GHz · -63 dBm」；
- 密码框：聚焦蓝色描边 + 眼睛切换明文；
- 记住密码开关（默认关）+ 右侧「保存后下次自动连接」；
- 整宽主按钮「连 接」；
- 底部「忘记此网络」红字（仅已保存时显示）；
- **键盘默认不显示**：点密码框才从底部弹出（占下半屏），「完成」/ 收起后回到隐藏态，
  **页面本身不退出**。

## 2.1 页面关系（覆盖式，两页而不是两态）

```
① 列表页（扫描结果）           ② 密码页（独立整页）
   点网络行  ────────────────▶   整页覆盖 ①
              ◀────────────────   返回 / 完成
```

- **① 的实例保留**：切到 ② 时不重新扫描、不清列表，分组与滚动位置原样保留
  （列表数据全在变量里，screen 对象由 EEZ 常驻）；
- **EEZ 两种落地**（都对，推荐 A）：
  - **A. 两个 screen**：`scr_list` / `scr_pwd`，行点击 `loadScreen(scr_pwd)`，
    返回/完成 `loadScreen(scr_list)`——零覆盖代码、零 z-order 问题；
  - **B. 单 screen + 全屏容器**：密码容器 `x=0 y=0 w=480 h=320`，`hiddenFlag`
    绑 `pwd_open`；容器同样是「覆盖」，以后要加滑入动画只需改这一层；
- **两种形态都支持**（对比见 `mockup_13_popup_forms`）：
  - **整页 320（主流程推荐）**：切页即可，无遮罩、无 z-order、无键盘顶起逻辑；
  - **半页 200（62%，宿主页需保留上下文时用）**：必须**全宽**（键盘才 464），
    且只放「密码框 + 连接」两件东西；需自行处理把手、遮罩、下滑关闭、焦点避让；
  - **反面**：半页里塞「记住密码 + 忘记 + 错误提示 + 键盘」——高度根本不够，
    必然挤压（上一代工程就是在抽屉里堆满，最后键盘被裁）。

### 为什么必须整页（三个好处，见 mockup_12_explain_keyboard）

1. **键盘最大化**：键盘由**屏幕**排版而不是容器——可用宽 464 → 键宽 **42.8**；
   塞进 408 卡片（本设计的组件容器）只剩 **34.8**（−19%），塞进 320 容器只剩
   **28.4**（−34%），字号被迫从 10.5 降到 9、误触上升。
   （键宽 =（可用宽 − 9×4）÷ 10；建议 ≥ 40）
2. **容器可复用**：同一个 WiFi 组件可以塞进任意尺寸的宿主容器（设置页卡片 408×176、
   侧栏、弹窗），**输入密码时一律升格为整页**——组件不用为每种容器再造一套小键盘。
3. **布局解耦**：列表在容器里的紧凑阈值/行高/字号怎么变，密码页与键盘都不受影响；
   容器内的 overflow / 裁剪 / 滚动也不会切掉键盘。

> 实现上：组件里的行点击只做一件事——请求宿主「打开全屏密码页」
> （`loadScreen(scr_pwd)` 或 `pwd_open=1`），绝不在组件内部画键盘。

## 4. 实现映射（EEZ 静态槽位）

- 列表：固定 5 槽（每槽 1 容器 + 5 label：名称/类型数值/锁/状态/信号条组）；
- 变量/槽：`ssid_N, auth_N, rssi_N, band_N, lock_N, saved_N, conn_N`（7 个）；
- 全局：`ap_count, scan_state, wifi_state, pick_ssid, saved_ssid, pwd_open`；
- 行点击 → `pick_ssid=ssid_N` → 进密码页（`loadScreen(scr_pwd)`，方案 B 则 `pwd_open=1`）；
- 密码页「连接」→ 连接并回列表；「返回/完成」→ 回列表（不改变连接状态）；
- 信号图示：EEZ 侧 4 个 3px 宽 rect，用 hiddenFlag 按 rssi_N 区间显示前 N 条。
