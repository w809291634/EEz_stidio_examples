| 常量 | 值 | 说明 |
|---|---|---|
| 页面内边距 | 16 | 内容区 x=16..464 |
| 行 | x=16, w=448, h=46, 间距 6 | 行顶：56 / 108 / 160 / 212 / 264（5 槽） |

- 返回 ‹ + 标题“输入密码”

- 记住密码开关 + 右侧“下次自动连接”

## 4. 实现映射（EEZ 静态槽位）

- 列表：固定 5 槽（每槽 1 容器 + 5 label：名称/类型数值/锁/状态/信号条组）；
- 变量/槽：`ssid_N, auth_N, rssi_N, band_N, lock_N, saved_N, conn_N`（7 个）；
- 全局：`ap_count, scan_state, wifi_state, pick_ssid, saved_ssid`；
- 行点击 → pick_ssid=ssid_N → loadScreen(密码页)；密码页返回 → loadScreen(列表页)；
- 信号图示：EEZ 侧 4 个 3px 宽 rect，用 hiddenFlag 按 rssi_N 区间显示前 N 条。

## 5. 状态覆盖

| 状态 | 表达 |
|---|---|
| 扫描中 | 副标题“扫描中…”+ 2 骨架行 + 刷新按钮禁用色 |
| 无网络 | 居中空态（图标 + 文案 + 刷新引导） |
| 连接中 | 该行状态位变“连接中…”，行描边 primary |
| 失败 | 该行下方 11px 红字“密码错误 · 再点重试” |
| 已连接 | 行描边成功色 + 绿点“已连接”（组置顶） |
| 已保存 | 蓝胶囊“已保存” |
