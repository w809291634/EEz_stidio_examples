## 2. 密码页（点击带锁行进入 · 独立整页）

- **整页覆盖**：密码页是一整页（独立 screen / 全屏容器），480×320 全部盖住列表，
  **不做半屏抽屉、不做弹层**；
- 返回 ‹（左上）+ SSID 18px + 副标题「WPA3 · 5 GHz · -63 dBm」；
- 密码框：聚焦蓝色描边 + 眼睛切换明文；
- 记住密码开关（默认关）+ 右侧「保存后下次自动连接」；
- 整宽主按钮「连 接」；
- 底部「忘记此网络」红字（仅已保存时显示）；
- **键盘默认不显示**：点密码框才从底部弹出（占下半屏），「完成」/ 收起后回到隐藏态，
  **页面本身不退出**。

## 2.1 页面关系（覆盖式，两页而不是两态）

```
① 列表（宿主页子容器）            ② 连接半页（覆盖在宿主页之上）
   点网络行  ────────────────▶     高 224，自底部上滑
              ◀────────────────     取消 / 下滑关闭
```

- **① 的实例保留**：打开半页时不重新扫描、不清列表，分组与滚动位置原样保留
  （数据全在变量里，宿主 screen 常驻）；
- **② 是半页（定稿）**，见 §6 与 `mockup_15_subcontainer_sheet`：
  - 高度 **224**（70%，与手机键盘占比相当）：把手 6 + 标题 20 + 输入行 36 + 间距 30 + 键盘 132；
  - **必须全宽**（可用 464 → 键宽 **42.8**）；塞进 408 卡片只剩 34.8、320 容器只剩 28.4，
    字号被迫降到 9、误触上升（键宽 =（可用宽 − 9×4）÷ 10，建议 ≥ 40）；
  - 只放「密码框 + 连接 + 全宽键盘」；**记住密码 / 忘记此网络 / 错误详情**放列表长按菜单；
  - 整页 320 仅在「宿主要求隐藏列表 / 内容确实放不下」时作为备选，不是默认；
- **EEZ 落地**：`overlay_root`（全屏容器，`hiddenFlag = pwd_open == 0`）挂在 **screen 根**，
  **不放进** `wifi_panel`——子对象会被父边界裁剪且坐标二次偏移（P-0007）；
- **组件边界**：组件里的行点击只做一件事——把 `pwd_open` 置 1，由宿主页画半页；
  **绝不在组件内部画键盘**（容器一变窄，键盘就跟着窄）。

## 6. 方案 C（当前采用）：列表在子容器 + 连接用半页（键盘式）

> 用户口径：**WiFi 扫描结果放在宿主页的子容器里；点连接弹半页，效果像键盘从底部升起。**

### 6.1 结构（从上到下 = z 序从高到低）

```
scr_host（宿主页 480×320）
├── card（设置卡片）
│   └── wifi_panel（User Widget 424×192）      ← 列表在这里，容器内可滚动
└── overlay_root（全屏 480×320，透明，默认 hidden）  ★ 必须挂在 screen 根
    ├── scrim（全屏 #000 45%，点它关闭）
    └── sheet（480×224，底部对齐）              ← 半页：输入行 + 键盘
        ├── handle 32×3 / 标题行（SSID + ×）
        ├── input_row：密码框 364×36 + 连接 76×36
        └── keyboard（464 宽 · 4 行 · 键高 30 · 键宽 42.8）
```

### 6.2 六条硬规则（每条都对应一条本地经验，别改）

| 规则 | 原因 | 依据 |
|---|---|---|
| **overlay_root 挂 screen 根，绝不放进 card/panel** | LVGL 子对象被父边界**裁剪**，且坐标以父内容区为基准 → 放进容器就只能盖住 424×192 | P-0007 嵌套坐标二次叠加 · 坑 16 |
| **panel 只发命令，不画弹层** | 组件要能塞进任意容器；弹层归宿主页管 | `reference/10_hw_ui_separation` §0.3 依赖方向 |
| **容器本身关 CLICKABLE，只有行容器开** | 装饰容器默认不响应，事件被容器吞掉 | P-0004 开关是装饰容器点了没反应 |
| **列表 = 普通容器 + scroll_dir=VER + 行绝对坐标** | EEZ 的 List(LVGL) 是 wip，无属性可配 | P-0152 可滚动列表 |
| **键盘别遍历 children** | LVGL 9.4 keyboard 是内嵌 buttonmatrix，`child_count` 恒 0 | P-0056 |
| **半页高度 ≥ 224** | 键盘 132 + 输入行 36 + 标题 20 + 把手/间距 36 | 见 6.3 预算 |

### 6.3 高度预算（320 屏，半页 224 = 70%，与手机键盘比例相当）

| 区 | 高 | 说明 |
|---|---|---|
| 把手 | 6 | 32×3 圆角条，示意可下滑 |
| 标题行 | 20 | SSID（13px）+ 右侧 ×；**错误时就地变红字**（省一行高度） |
| 输入行 | 36 | 密码框 364×36 + 连接按钮 76×36（同行，省高度） |
| 间距 | 30 | 6+8+8+8 |
| 键盘 | 132 | 4 行 × 30 + 3 × 4 |
| **合计** | **224** | 低于 210 键高会掉到 26 以下，手指点不准 |

### 6.4 交互时序

1. 点行 → `pick_ssid` 赋值 + `pwd_open=1` → scrim 淡入、sheet 200ms 上滑；
2. 点遮罩 / × / 下滑 → `pwd_open=0`，**不改变连接状态**；
3. 点连接 → `cmd_connect=1` + `pwd` + `remember`；
4. `wifi_state=1` → 按钮变「连接中…」并禁用（防重复投递）；
5. `wifi_state=2` → 半页自动收起 + 该行变绿「已连接」；
6. `wifi_state=3` → 标题行红字「密码错误」，密码框清空并保持焦点（键盘不收）。

### 6.5 为什么不做整页

主流程（输密码 + 连接）半页就能装下；「记住密码 / 忘记此网络 / 错误详情」这些低频操作
移到**列表长按菜单**，半页永远只做一件事 —— 这是它稳定的原因。

### 6.6 变量收敛（相比 §1.3 少 2 个）

- **新增**：`pwd_open`（1 = 半页展示中）
- **删除**：`status_N` / `row_visible_N` —— 它们是**派生量**，改由 EEZ 表达式从
  `conn_N / saved_N / lock_N / rssi_N` 现算（`reference/10_hw_ui_separation` §4.3：
  派生量在 getter 里现算，不许扩接口，否则出现两个真值源）
