## 网格常量（实现时照抄，勿手算）

| 常量 | 值 |
|---|---|
| 页面 | 480×320，内边距 16（内容区 16..464） |
| 行 | x=16, w=448, h=46, 行距 6（pitch 52） |
| 组 1 | 标签基线 62，行顶 68 / 120 |
| 组 2 | 标签基线 184（右端「共 N 个」），行顶 190 / 242 |
| 信号条 | x=30，4 根宽 3.6、间距 6，高度 5/8/11/14，**底边 row+34** |
| 文本 | x=58；SSID 基线 row+19（14.5px）；副行基线 row+34（11px） |
| 锁 | x=368（10×8，y=row+20，视觉中心=行中心） |
| 状态槽 | **右缘统一 450**，垂直中心 row+23，胶囊高 17；已连接 52 / 已保存 46 / 连接中 50 / 失败 58 |
| 底部提示 | 基线 306，居中 |

## 规则

1. **不要手改 SVG**——改 `design/mockup_gen.py` 的常量或 `SCREENS` 内容后重新生成；
2. 生成脚本内带断言：状态胶囊右缘一致、锁垂直居中（≤1.5px）、分组不重叠、列表不溢出；
3. 新增状态：在脚本里加一个 `sc_xxx(s)` 函数 + 往 `SCREENS` 追加一行即可。
