# 设计图目录（mockups）

| 文件 | 版本 | 说明 |
|---|---|---|
| `mockup_v1_list.svg` | **v1（用户确认版）** | 第一版列表：四格信号图示 + 名称 + 类型·强度·频段 + 锁 + 状态（已连接点/已保存胶囊/›） |
| `mockup_list.svg` | v2（网格对齐版） | 由 `design/mockup_gen.py` 生成：状态胶囊统一胶囊化并右缘对齐、锁垂直居中，坐标由单一网格常量驱动 |

- 打开方式：浏览器直接打开 SVG（矢量，无损缩放）。
- 修改方式：**不要手改 SVG**。要调整请改 `design/mockup_gen.py` 里的网格常量
  （行高/基线/右缘/锁位），重新生成即全图自动对齐。
- 与实现的关系：`DESIGN.md` 的常量表与本目录图一一对应，实现时照抄常量。
